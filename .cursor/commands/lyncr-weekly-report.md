# Lyncr Weekly Product Report

Act as **Lyncr Boss**. Run a **read-only** weekly Product Readiness pass.

1. Load `.cursor/skills/lyncr-product-readiness/SKILL.md`.
2. Delegate briefly to: Product Doctor, Solo Owner Simulator, Flow Tester (top flows), Reliability Watcher, Data Analyst (if data available), UX (top interaction issue). Skip agents that have nothing evidence-based.
3. Do **not** write product code, deploy, send SMS, create payments, or change Telnyx.
4. Deliver the owner-facing report in the exact **LYNCR WEEKLY PRODUCT REPORT** format from the readiness skill.
5. End with one practical recommendation and one decision (if any).
